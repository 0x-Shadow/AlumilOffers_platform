# Εγκατάσταση βήμα-βήμα (Windows)

## Τι χρειάζεσαι
- Windows 10 ή 11
- Python 3.11+ (μόνο αν τρέχεις από κώδικα — το `.exe` δεν θέλει τίποτα)

## Βήμα 1 — Python (παράλειψέ το αν έχεις το .exe)
1. Κατέβασε Python από <https://www.python.org/downloads/>.
2. Στην εγκατάσταση τσέκαρε το **«Add python.exe to PATH»** και πάτα Install.

## Βήμα 2 — Κατέβασμα προγράμματος
- Κατέβασε το ZIP του repository (κουμπί **Code → Download ZIP**) και αποσυμπίεσέ το,
  ή με git: `git clone <repo-url>`.

## Βήμα 3 — Βιβλιοθήκες
Άνοιξε τερματικό μέσα στον φάκελο και τρέξε:

```bat
pip install -r requirements.txt
```

## Βήμα 4 — Εκκίνηση
- Διπλό κλικ στο `RUN_APP.bat`, ή
- `python app.py`

(Η άδεια χρήσης γίνεται αποδεκτή μία φορά, τρέχοντας το Setup.)

## Βήμα 5 — Φτιάξιμο .exe (προαιρετικό)
```bat
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name AluminaOffers app.py
```
Το `.exe` βγαίνει στον φάκελο `dist/`. Βάλ' το μέσα στον φάκελο του
προγράμματος — εκεί αποθηκεύονται η βάση (`alumina.db`), οι εικόνες
(`Sxedia/`) και τα PDF (`PDF_Prosfores/`).

> Το SmartScreen των Windows ίσως προειδοποιήσει επειδή το `.exe` δεν
> είναι υπογεγραμμένο → *More info → Run anyway*.

## Πρώτες ρυθμίσεις
1. **Στοιχεία & Λογότυπο** → βάλε επωνυμία, ΑΦΜ, τηλέφωνα + ανέβασε λογότυπο.
2. **Κατάλογος → Σχέδια** → «Εισαγωγή φακέλου» για μαζική εισαγωγή φωτογραφιών.
3. **Νέα Προσφορά** → πελάτης, γραμμές, **ΑΠΟΘΗΚΕΥΣΗ + PDF**.
