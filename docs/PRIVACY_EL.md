# Απόρρητο — AluminaOffers

- Η εφαρμογή λειτουργεί **100% τοπικά**. Δεν δημιουργεί λογαριασμούς,
  δεν συνδέεται στο διαδίκτυο και δεν αποστέλλει δεδομένα πουθενά.
- Τα δεδομένα σας βρίσκονται μόνο στον φάκελο της εφαρμογής:
  - `alumina.db` — προσφορές, πελάτες, υλικά, σχέδια, ρυθμίσεις
  - `Sxedia/` — φωτογραφίες σχεδίων
  - `logo.png` — το λογότυπό σας
  - `PDF_Prosfores/` — τα PDF που εξάγετε
- Εσείς ελέγχετε τα αρχεία αυτά: μεταφορά, backup και διαγραφή
  γίνονται από εσάς, με απλή διαχείριση αρχείων των Windows.
- Τα PDF τα στέλνετε εσείς (email, Viber κ.λπ.) — η εφαρμογή δεν
  τα αποστέλλει αυτόματα.
