# Απόρρητο — Europa

- Η εφαρμογή λειτουργεί **100% τοπικά**. Δεν δημιουργεί λογαριασμούς και
  δεν αποστέλλει δεδομένα πουθενά. Η μόνη σύνδεση είναι ο έλεγχος
  ενημερώσεων στο GitHub (χωρίς αποστολή προσωπικών δεδομένων) — μπορείτε
  να τον απενεργοποιήσετε ορίζοντας `EUROPA_NO_UPDATE_CHECK=1`.
- Τα δεδομένα σας βρίσκονται μόνο στον φάκελο χρήστη
  `%APPDATA%\Europa\`:
  - `europa.db` — προσφορές, πελάτες, υλικά, σχέδια, ρυθμίσεις
  - `Sxedia/` — φωτογραφίες σχεδίων
  - `logo.png` — το λογότυπό σας
  - `PDF_Prosfores/` — τα PDF που εξάγετε
- Εσείς ελέγχετε τα αρχεία αυτά: μεταφορά, backup και διαγραφή
  γίνονται από εσάς, με απλή διαχείριση αρχείων των Windows.
- Τα PDF τα στέλνετε εσείς (email, Viber κ.λπ.) — η εφαρμογή δεν
  τα αποστέλλει αυτόματα.
